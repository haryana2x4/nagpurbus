# NagpurBus — Data Sources, Licences & Attribution Register

This register records **every** data source used by NagpurBus, its licence, required attribution, verification status, and exact limitations in accordance with the project's **Truth in Data** and **Data Ethics** rules.

> **Strict Policy:** NagpurBus does **not** scrape, reverse-engineer, or invoke the private APIs of Chalo, the Aapli Bus app (DIMTS), or any proprietary transit application.
